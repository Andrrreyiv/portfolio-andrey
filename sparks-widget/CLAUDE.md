## Что это за проект

Демо AI-ассистента (чат-виджет) для клиента **ТД Спаркс** (sparks.su) — поставщик
промышленного оборудования (мотор-редукторы, приводы). Виджет встраивается на сайт,
помогает посетителю подобрать оборудование, отвечает на вопросы, собирает заявку.

Это **референс-демо для клиента и его дизайнера** — показывает весь функционал обоих
этапов проекта в одном файле. Не продакшн-код, а наглядный прототип «как это будет».

**Клиент:** ООО ТД «Спаркс». Контакт: Павел.
**Исполнитель (фрилансер):** Андрей Брыкун.

## Функционал — 1 ЭТАП (базовый)

- Подбор оборудования по шагам: тип → мощность → монтаж → результат (карточка позиции)
- Навигация и ответы на вопросы по сайту
- Ветка «только менеджер» — для позиций без характеристик в базе (бот не подбирает сам)
- Заявка в **AmoCRM** с чекбоксом согласия **152-ФЗ** (непредзаполнённый, shake при пропуске)
- Учёт рабочего времени (`isWorkHours()`) — живой чат предлагается только в рабочие часы

## Функционал — 2 ЭТАП (помечен фиолетовым бейджем «2 ЭТАП»)

Показан в этом же демо, чтобы клиент и дизайнер видели полный продукт и границу этапов:

- **Цена/наличие из 1С** — карточка NMRV 063: 18 940 ₽ за шт. с НДС, «В наличии · Москва (7 шт.)»
- **Инженерный расчёт привода** — момент 447 Н·м, i=30, сервис-фактор 1.4, рекомендация
  NMRV 063 · 2.2 кВт, запас по нагрузке 40%
- **Живой чат-оператор** — Мария (аватар «М», тег «менеджер»), диалог → форма контакта

## Дизайн-токены

Все цвета в `:root` в начале `<style>`. Взяты автоматически с sparks.su, требуют
подтверждения дизайнером. Ключевые: основной синий `--brand:#2677C2`, акцент
оранжевый `--accent:#F97316`. Правило 60-30-10, сетка 8px. Анимации на GSAP
(появление сообщений, stagger чипов, shimmer карточки, пульс-кольцо кнопки),
с учётом `prefers-reduced-motion` через `gsap.matchMedia`.

Брендинг Claude/ИИ-провайдера убран (footer «Работает на базе ИИ · ТД Спаркс») —
по 152-ФЗ и чтобы не раскрывать техстек клиенту.

## Мобильные (проверено на 375px)

- Панель разворачивается на весь экран (`100dvh` + safe-area под чёлку/жесты)
- Нет горизонтального скролла, кнопка-пузырь 66×66px
- Поля формы подняты до 16px на мобильных (`@media(max-width:460px)`) — иначе iOS
  Safari зумит страницу при фокусе на input

## Что должен сделать дизайнер клиента

Виджет рабочий по логике. Дизайнер НЕ программирует — приводит вид под фирстиль:

1. **Цвета** — отдать точные HEX бренда, подставить в `:root`
2. **Аватар и иконка** — аватарка ассистента (шапка) + иконка на кнопке-пузыре (SVG/PNG 96×96 2x)
3. **Шрифт** — если у бренда свой (woff2), подключить вместо системного
4. **Микротексты** — пройти реплики бота, править под голос бренда (тексты в JS-функциях)
5. **Иконки топиков** — сейчас эмодзи (🔍 🧮 📦 👤), можно заменить на фирменные SVG

Дизайнеру НЕ трогать: сценарии диалога, GSAP-анимации, интеграции AmoCRM/1С,
чекбокс 152-ФЗ, логику «2 этапа».

Формат передачи: одним сообщением — HEX, шрифт, аватар+иконка, правки текстов.
