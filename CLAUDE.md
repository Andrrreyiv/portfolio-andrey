Статика без фреймворка: главная + страницы кейсов. С 10.10 код разнесён по файлам

### Как устроено после редизайна 10.10

```
index.html                 главная (разметка руками; nav/footer вставляет сборка по маркерам <!--#nav-->)
cases/<slug>/index.html    СОБИРАЮТСЯ — руками не править, править content/cases.json
content/cases.json         тексты кейсов; у каждой цифры поле source (тест честности)
templates/case.html        каркас страницы кейса;  partials/nav.html, footer.html — с {{root}}
scripts/build.mjs          node scripts/build.mjs → cases/*, nav/footer в index.html, sitemap.xml
scripts/images.py          PNG-исходники (в т.ч. из соседних репо) → assets/img/*-<ширина>.webp
scripts/og.py              assets/og/*.png 1200×630 + favicon-32/apple-touch (нужны полные TTF Playfair/Onest)
assets/css                 tokens (тема, шрифты) · base (общее) · home · case
assets/js                  core (Lenis+GSAP, тема, магнит, появления) · home (сценарий) · gl (WebGL2) · case
assets/vendor              gsap 3.15, ScrollTrigger, SplitText, lenis 1.3.26 — свои копии, CDN в РФ ненадёжен
assets/fonts               Playfair (opsz=144, wdth 87.5–100, wght 400–700) 94 КБ, курсив 56, Onest 25, JetBrains Mono
```

- **Тема:** тёмная по умолчанию (`:root`), светлая — `data-theme="light"`, выбор в `localStorage.theme`.
- **WebGL** (`gl.js`): облако частиц на чистом WebGL2 без Three.js (Three — 195 КБ gzip ради одного drawArrays).
  Формы: «АБ» → пыль → форма с номером → облака чата → стеновые панели → пыль → «АБ». Фазу по прокрутке
  считает `driveGL` в `home.js` по опорным точкам; нет WebGL2 / reduced-motion / saveData / <4 ядер → контур `.hero-mark`.
- **Лента работ:** на ≥1024 и без reduced-motion `gsap.matchMedia` ставит `html.has-pin` и закрепляет `.work-pin`.
- **Страховка:** `<head>` снимает класс `.js` через 4 с, если `core.js` не выставил `window.__siteOk` — иначе
  `[data-reveal]` и заголовки остались бы скрытыми навсегда.
- **Тесты:** `node --test tests/*.test.mjs` — заглушка Спаркса (8) + сайт (8): сборка свежая, ссылки и картинки
  существуют, нет Pages-демо конструкторов / `widget.sparks.su` / `sparks-widget-live`, у цифр есть source.

### 2026-08-08, вечер — драматический редизайн (коммит `2f82d35`)
- 🔴 **Fraunces не имел кириллицы.** Все русские заголовки сайта с самого начала
  рисовались системной **Georgia**, а не заявленным шрифтом. Проверка: запросить
  `fonts.googleapis.com/css2?family=<Имя>` с полным браузерным User-Agent и
  посмотреть комментарии сабсетов (`/* cyrillic */`). С коротким UA Google отдаёт
  урезанный ответ и кириллица «пропадает» у всех семейств — метод даст ложь.
  Заменён на **Playfair** (не Playfair Display): есть cyrillic + cyrillic-ext,
  оси `opsz 5..1200`, `wdth`, `wght 300..900`.
- **Тёмная тема** на `:root[data-theme="dark"]`. Все полупрозрачные поверхности
  сведены к двум триплетам `--ink-rgb` / `--paper-rgb`, тема меняет их вместо
  правки 17 отдельных `rgba()`. Тема ставится на `<html>` блокирующим скриптом
  в `<head>` — иначе тёмному посетителю мигает белым при каждой загрузке.
- ⚠️ **Зерно надо переключать вместе с темой:** `mix-blend-mode:multiply` поверх
  near-black не рисует ничего. В тёмной — `overlay` и меньше непрозрачность
  (`--grain-blend` / `--grain-op`).
- ⚠️ **Стопка карточек (stacking cards) отвергнута осознанно.** Кейсы сильно
  разной высоты и с большим объёмом текста — стопка обрезала бы содержимое.
  Вместо неё закреплённый (`sticky`) визуал: скриншот стоит, текст едет рядом.
  Для этого `.case` обязан уйти с `align-items:center` на `start`, иначе
  grid-ребёнок не липнет вовсе.
- ⚠️ **`view()` замирает на sticky-элементе.** У прилипшего элемента прямоугольник
  в скроллпорте перестаёт двигаться, и view-таймлайн встаёт посреди анимации.
  Поэтому `view-timeline-name:--case` объявлен на **`.case`** (он не sticky),
  а потребляет его потомок `.plate img`.
- ⚠️ **Магнитная кнопка убивала отклик на нажатие.** JS писал `style.transform`,
  inline-значение, которое `:active` перебить не может — press-feedback не
  работал вообще на устройствах с курсором. Магнит, подъём и нажатие разведены
  по custom properties (`--tx/--ty/--lift/--press`) и складываются в один
  `transform`.
- ⚠️ **Прогресс-бар:** при `animation-timeline:scroll()` обработчик скролла
  обязан перестать писать `style.width`, иначе inline перебивает CSS и полоса
  залипает на 100%. Флаг `progNative`.
- Проверено замерами: оси заголовка идут `wght 330→640`, `opsz 8→120`;
  12/12 визуалов sticky; на мобильном sticky выключен, горизонтальной прокрутки
  нет; при `prefers-reduced-motion` кинетика выключается (`fvs: normal`),
  контент виден, ошибок в консоли нет.

  с осадкой масштаба, у картинок скролл-параллакс ±14px.
- ⚠️ **Глифы проверять в браузере, а не в редакторе:** `Inter` не содержит U+21B3 (`↳`),
  браузер молча подставлял чужой шрифт и в подписи под репликой читалось «Ĭ, ответ на
  основе...». Заменено на `→` (U+2192, в Inter есть) — коммит `61ffd2f`. Правило: любой
  небуквенный символ в вёрстке сверять скриншотом, в исходнике он выглядит правильно всегда.
- ⚠️ **Грабля, стоившая времени:** элемент с `clip-path:inset(0 0 100% 0)` сообщает
  IntersectionObserver нулевую площадь пересечения и **никогда не пересекает порог**, который
  этот clip-path снимает — сам себя блокирует. Поэтому `.plate` наблюдаются **через родителя**
  `.case-visual`, а не напрямую.
- ⚠️ Параллакс пишет только `--py`, а не `transform` целиком: инлайновый `transform` перебил бы
  CSS-осадку масштаба. Масштаб вынесен в `@property --ps`, чтобы анимировать его отдельно —
  иначе drift при скролле тянулся бы через ту же кривую 1.5s и ощущался вязким.
- Добавлен `<noscript>`-стиль: без JS вход-анимации никто не снимет и страница будет пустой.
