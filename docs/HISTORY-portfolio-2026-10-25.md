### Как устроено после редизайна 10.10

```
index.html                 главная (разметка руками; nav/footer вставляет сборка по маркерам <!--#nav-->)
cases/<slug>/index.html    СОБИРАЮТСЯ — руками не править, править content/cases.json
content/cases.json         тексты кейсов; у каждой цифры поле source (тест честности)
templates/case.html        каркас страницы кейса;  partials/nav.html, footer.html — с {{root}}
scripts/build.mjs          node scripts/build.mjs → cases/*, nav/footer в index.html, sitemap.xml
scripts/images.py          PNG-исходники (в т.ч. из соседних репо) → assets/img/*-<ширина>.webp
scripts/og.py              assets/og/*.png 1200×630 + favicon-32/apple-touch (нужны полные TTF Playfair/Onest)
scripts/record.py          видео работ → assets/video/<имя>.webm/.mp4/.webp (см. «Третий круг»)
assets/css                 tokens (тема, шрифты) · base (общее) · home · case
assets/js                  core (Lenis+GSAP, тема, магнит, появления) · home (сценарий) · gl (WebGL2) · case
assets/vendor              gsap 3.15, ScrollTrigger, SplitText, lenis 1.3.26 — свои копии, CDN в РФ ненадёжен
assets/fonts               Playfair (opsz=144, wdth 87.5–100, wght 400–700) 94 КБ, курсив 56, Onest 25, JetBrains Mono
```

- **Тема:** тёмная по умолчанию (`:root`), светлая — `data-theme="light"`, выбор в `localStorage.theme`.
- **WebGL** (`gl.js`): облако частиц на чистом WebGL2 без Three.js (Three — 195 КБ gzip ради одного drawArrays).
  Формы: «АБ» (первый экран и «Обо мне») → пыль → форма → чат → панели → окно сайта → лупа → пыль → сеть → пыль → «?» → «АБ». Фазу по прокрутке
  считает `driveGL` в `home.js` по опорным точкам; нет WebGL2 / reduced-motion / saveData / <4 ядер → контур `.hero-mark`.
- **Лента работ:** на ≥1024 и без reduced-motion `gsap.matchMedia` ставит `html.has-pin` и закрепляет `.work-pin`.
- **Страховка:** `<head>` снимает класс `.js` через 4 с, если `core.js` не выставил `window.__siteOk` — иначе
  `[data-reveal]` и заголовки остались бы скрытыми навсегда.
- **Тесты:** `node --test tests/*.test.mjs` — заглушка Спаркса (8) + сайт (9): сборка свежая, ссылки и картинки
  существуют, нет Pages-демо конструкторов / `widget.sparks.su` / `sparks-widget-live`, у цифр есть source.
