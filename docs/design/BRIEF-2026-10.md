# Бриф редизайна портфолио, 2026-10

Источник решений — чат с владельцем 10.10, план `~/.claude/plans/shimmering-swinging-wren.md`.

## Что делаем
Второй драматический редизайн `andrrreyiv.github.io/portfolio-andrey` (первый — 08.08, «журнальный»).
Главная + отдельные страницы ключевых кейсов. Статика без фреймворка, GitHub Pages.

## Для кого
Владельцы и менеджеры малого и среднего бизнеса из РФ, пришедшие с Profi.ru, FL.ru, Kwork
или по ссылке из отклика. Решают за 30–90 секунд: «этот человек сделает мою задачу?»

## Метрика успеха
1. Переход в Telegram / звонок / почта со страницы (кнопка «Обсудить задачу»).
2. Открытие страницы кейса и время на ней (доказательство, а не обещание).
3. Технические пороги: LCP ≤ 2,0 с на мобильном, CLS ≤ 0,05, INP ≤ 200 мс, Lighthouse a11y/SEO 100.

## Направление
Тёмная кинематографичная тема по умолчанию, светлая «бумажная» — переключателем.
- Тонированный уголь `#100E0C`, текст `#EFE8DD`, один «раскалённый» акцент `#FF5B2E`,
  холодный `#9DB4C8` только для данных.
- Playfair (opsz 144, оси ширины и веса) — огромный дисплей; Onest — текст; JetBrains Mono — индексы.
  Шрифты свои, в `assets/fonts/`, собраны из google/fonts (см. CLAUDE.md, раздел шрифтов).
- Подпись сайта: WebGL-облако частиц в первом экране собирается в «АБ» и при прокрутке перетекает
  в силуэты кейсов (форма → чат → стеновые панели). Без WebGL — статичный кадр.
- GSAP + ScrollTrigger + Lenis, свои копии в `assets/vendor/`.

## Обязательное содержание
- Хаб jetronsport.ru: сайт + три боевых конструктора (форма, футболки, постеры).
- ТД «Спаркс» открыто, ссылка `https://sparks.su/`, без `widget.sparks.su` и без демо-папки.
- Стенариум — `https://stenarium.ru/visualizer`.
- Типовые примеры 1–5 — тексты и цифры без изменений (решение владельца), только новый стиль.

## Запреты
Эмодзи-иконки, bento без причины, glassmorphism, неон, mesh-градиенты, градиентный текст,
чистый `#000`, «три одинаковые карточки», выдуманные отзывы и цифры. У каждой цифры реального
кейса — источник в `content/cases.json`. Никакой автоматики по jetronsport.ru.
