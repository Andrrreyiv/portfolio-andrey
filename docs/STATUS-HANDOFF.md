# Передача: четвёртый круг портфолио (18–19.10.2026)

Запрос владельца: «чёрный и бежевый вперемежку, на бежевом та же анимация», «дёргается резко», «сразу открывается
Андрианов», «проверь на телефоне», «реально WOW и профессионально».

## Сделано и проверено 19.10 (тесты 22/22, консоль чистая)
- Главы чередуются (петроль убран), частицы на бумаге (слой `.tone-bands`, зоны `uZone`), фигуры лупа/сеть/«?».
- Плавность: лента — таймлайн «переезд → пауза» без автодоводки, ×1,6, `pinType:'transform'`, только `pointer:fine`;
  `scrub: true` везде; одно видео за раз; волна от тапа; WebGL после вступления; затухания по времени; меню без скачка
  высоты; бегущие строки на паузе вне экрана; на телефоне без зерна, blur и clip-path финала.
- WOW: сборка «АБ» из пыли, свечение частиц на чёрном, счётчики цифр (и «3 063 → 70 мс» на кейсе), первый экран громче,
  медиа ленты крупнее, кнопка Telegram с прокруткой надписи, на кейсе плита под видео и обложка следующего кейса.
- Типографика: маска слова с запасом (курсив не режется), `&nbsp;` перед тире, SplitText `reduceWhiteSpace:false`.
- Замер: десктоп 1440 p95 8,2 мс, max 24, CLS 0, самоходов 0; телефон 390 ×4 CPU p95 23 мс, max 68, CLS 0.

## Не сделано (предложения «арт-директора», риск выше пользы сейчас)
- Медиа сцен на телефоне во всю ширину с раскрытием карточкой (clip-path по видео на Android дорог).
- Нарезка `ready()` по idle (старт ×4 — 489 мс скрипта), двойной проход ScrollTrigger за кадр (~1 мс при ×4).
