Игры для уроков по подписке

Учителя покупают на englishgamematters.ru подписку на игры для уроков. Я сделал сервис, который проверяет подписку при каждом открытии игры, и сервер комнат, куда класс входит по QR-коду.

136проверок доступа в итоговом прогоне, провалов 0

Открыть englishgamematters.ru ↗

Игры лежат в закрытом хранилище, и открыть их можно только через мой сервис: ссылка учителя несёт его почту в зашифрованном виде, срок подписки сверяется с базой, при любом сбое доступ закрыт. Для живой игры в классе я поднял сервер комнат Sketch Relay: учитель получает пропуск на 10 минут, ученики входят по QR-коду, в комнате до 30 игроков.

Задача

Учитель платит за подписку и получает игры для уроков. Значит, игра должна открываться только у того, чья подписка действует, и не открываться по пересланной ссылке.

Вторая часть — живая игра всем классом. Учитель показывает комнату на экране, ученики заходят с телефонов без регистрации и рисуют по описанию на английском.

Как устроено

  1. 01

    Ссылка учителя несёт его почту в зашифрованном виде; при каждом открытии игры сервис сверяет срок подписки с базой.

  2. 02

    Игры лежат в закрытом хранилище: прямой адрес не открывается, только через сервис.

  3. 03

    При сбое базы или сети доступ закрыт, а не открыт: ошибка не превращается в бесплатную игру.

  4. 04

    На Тильде — загрузчик игр с кнопкой «Копировать ссылку», сторож страниц и запасная проверка срока; новые тарифы Продамуса подключаются без правки сценариев оплаты.

  5. 05

    Сервер комнат: пропуск учителя на 10 минут с подписью Ed25519, вход учеников по QR-коду, до 30 игроков. Идея и интерфейс игры — прототип автора сайта, сервер и допуск — мои.
